# 01 · 管线总览：一条视频的 7 个阶段

> 每天 06:00（Asia/Shanghai）cron 自动触发，全程无人值守，超时预算 1.5 小时。

---

## 阶段 1 — 定时触发 ⏰

- 任务 id：`daily-money-video`
- 频率：每天 06:00，时区 Asia/Shanghai
- 完成后把成片作为附件发到主聊天，并附一句话介绍当天题材

## 阶段 2 — 调研选题 🔍

**先爬全网，再定题材，绝不拍脑袋。**

1. 用实时网络搜索找：近期省钱技巧、消费陷阱、坑钱套路
2. 对照 `used_topics.md` 黑名单，避开做过的题材
3. 输出：1 个新鲜角度 + 3~4 个**带数字**的点（每个数字必须有小票/算式/消费情境）

已用题材（不得直接重复）：
`满减凑单`、`贪便宜反复复购`、`大促囤货导致过期`、`为省钱办理付费会员`

## 阶段 3 — 写分镜 brief 🎨

见 [10 Brief 模板](10-brief-template.md)。固定结构：

```
钩子 4s → 每个点 5s → 收束 6s，总时长 ≤ 40s
```

风格：2.5D 贴纸风 + 站酷快乐体，错位/旋转排版。

## 阶段 4 — 逐帧拍摄 📸

- 核心是一个**纯时间函数** `window.render(t)`：输入第几秒，输出那一秒的完整画面
- 无头 Chromium 走 `file://` 协议截图，30fps，30 秒 ≈ 900 帧 ≈ 7 分钟
- 改局部只重渲受影响区间，不用全量返工

详见 [03 HTML 路线](03-route-html.md) / [04 Remotion 路线](04-route-remotion.md)。

## 阶段 5 — 质检 🔎（三道闸，不过不交付）

| 闸 | 查什么 | 标准 |
|---|---|---|
| 静帧 | 每幕抽帧看构图、错字、元素重叠 | 零错字、零穿帮 |
| 转场 | 场景切换处 0.45s 重叠带 | 改过任一场景必须重渲相邻转场帧 |
| 响度 | 每 2 秒一段的 RMS 曲线 | 无"前小后大"爬坡（见 [06](06-audio.md) 的 amix 坑） |

## 阶段 6 — 音频 🎵

1. BGM 裁剪到与视频**等长**，结尾 2 秒淡出，做响度标准化
2. 数字/卡片弹出配"啵"音效、印章配闷响 —— 用 numpy 在时域直接叠加，**禁用 ffmpeg amix 多输入混音**（原因见 [06](06-audio.md)）
3. 混音后检查峰值 < 1.0，无削波

## 阶段 7 — 合成 · 交付 🎬

1. ffmpeg 组装：H.264 视频 + AAC 音频
2. 存档：`outputs/YYYY-MM-DD_题材.mp4`（**每次用新文件名**，防客户端缓存旧版）
3. 发附件到聊天 + 一句话介绍
4. 把当天题材追加进 `used_topics.md`
